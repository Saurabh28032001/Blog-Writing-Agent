# Blog Writing Agent

An AI agent that writes blog posts end to end, built with **LangGraph** and OpenAI models. The project is built up in three stages, from a simple single-prompt agent to a research-backed workflow.

## What it does

Give the agent a topic and it produces a complete blog post in Markdown. Sample posts generated by the agent are in the [`outputs/`](outputs/) folder.

## Project structure

```
Blog-Writing-Agent/
├── 1_bwa_basic.ipynb                # Stage 1: basic LangGraph agent
├── 2_bwa_improved_prompting.ipynb   # Stage 2: improved prompting
├── 3_bwa_research.ipynb             # Stage 3: research-backed blog writing
├── outputs/                         # Blog posts generated by the agent
├── requirements.txt
├── .env.example                     # Template for required environment variables
└── README.md
```

## The three stages

| Notebook | What it adds |
|----------|--------------|
| `1_bwa_basic.ipynb` | A basic LangGraph workflow that takes a topic and generates a blog post |
| `2_bwa_improved_prompting.ipynb` | Better prompt design for structure, tone and quality of the output |
| `3_bwa_research.ipynb` | A research step that gathers information on the topic before writing |

## How it works

The agent is a LangGraph state graph. Each node handles one step of the process, and shared state is passed between nodes until the final post is written.

```
topic  →  [plan / research]  →  [write]  →  Markdown blog post
```

> Edit this section to match the exact nodes and edges in your graph. A diagram works well here (LangGraph can export one with `graph.get_graph().draw_mermaid_png()`).

## Tech stack

- Python
- [LangGraph](https://github.com/langchain-ai/langgraph) for agent orchestration
- LangChain with OpenAI models for content generation
- Jupyter Notebook

## Setup

1. **Clone the repo**

   ```bash
   git clone https://github.com/Saurabh28032001/Blog-Writing-Agent.git
   cd Blog-Writing-Agent
   ```

2. **Create and activate a virtual environment**

   ```bash
   python -m venv bwaenv
   # Windows
   bwaenv\Scripts\activate
   # macOS / Linux
   source bwaenv/bin/activate
   ```

3. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

4. **Add your API key**

   Copy `.env.example` to `.env` and fill in your values:

   ```
   OPENAI_API_KEY=your_key_here
   ```

   Never commit your `.env` file.

## Usage

Start Jupyter and run the notebooks in order:

```bash
jupyter notebook
```

Start with `1_bwa_basic.ipynb`, then move on to the later notebooks. The final notebook, `3_bwa_research.ipynb`, is the most complete version of the agent.
